# BRB Bunny 🐰

A cute, simple hall pass kiosk for one classroom iPad (Room D211). Kids tap their name, pick where they're going, and tap their name again when they're back.

- Static files only. No accounts, no cloud, no analytics, **no student data in this repo**.
- The class list and pass log are stored only on the iPad (local storage). Backups are files the teacher saves.
- Works offline (service worker) after the first visit.
- Restroom is never refused: the most the kiosk says is "You're next!" or "Please check with Mrs. Plett 💜".
